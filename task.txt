Представьте, что вы разрабатываете сервис для хранения изображений, но объём памяти на сервере ограничен. Ваша задача — уменьшить объём данных изображения с помощью SVD так, чтобы картинка всё ещё оставалась узнаваемой.

Что нужно сделать:

Возьмите любое изображение .jpg или .png.
Загрузите его в Python с помощью PIL.
Переведите изображение в чёрно-белый формат.
Преобразуйте изображение в numpy-матрицу и выведите её размер.
Выполните SVD-разложение матрицы:

U, S, VT = np.linalg.svd(...)

Восстановите изображение, используя разное количество компонент:

k = 5, 10, 25, 50, 100

Для каждого значения k покажите полученное изображение и сравните его с оригиналом.
Посчитайте количество данных, которые необходимо хранить до и после сжатия.

Исходный размер:

height * width

Размер после SVD:

height * k + k + k * width

Рассчитайте, во сколько раз уменьшилось количество хранимых данных:

compression = original_size / compressed_size

Для каждого значения k выведите примерно такой результат:

Количество компонент: 50
Исходное количество значений: ...
После сжатия: ...
Степень сжатия: ... раз

Главная задача: подобрать минимальное количество компонент k, при котором изображение остаётся хорошо узнаваемым, а количество хранимых данных уменьшается минимум в 10 раз.

В конце сделайте вывод:

какое значение k вы выбрали;
во сколько раз удалось сжать данные;
насколько сильно изменилось качество изображения;
почему вы считаете выбранное значение оптимальным.
